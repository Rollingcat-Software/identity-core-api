# Biometric Step-Up Contract (Identity Core API)

This document freezes the backend contract for biometric step-up in `identity-core-api`.

## 1) Endpoints

Base path: `/api/v1/auth/biometric`

### 1.1 Register Device

- **Method/Path**: `POST /api/v1/auth/biometric/devices`
- **Auth**: Bearer access token required
- **Request body**:

```json
{
  "keyId": "key-123",
  "platform": "ANDROID",
  "publicKeyJwk": {
    "kty": "EC",
    "crv": "P-256",
    "x": "<base64url-x>",
    "y": "<base64url-y>",
    "kid": "optional-kid"
  },
  "deviceLabel": "Pixel 8"
}
```

- **Response**:

```json
{
  "deviceId": "uuid"
}
```

### 1.2 Create Challenge

- **Method/Path**: `POST /api/v1/auth/biometric/challenge`
- **Auth**: Bearer access token required
- **Request body**: none
- **Response**:

```json
{
  "challengeId": "uuid",
  "nonceBase64": "<nonce>",
  "expiresAt": "2026-02-19T16:30:00Z"
}
```

### 1.3 Verify Challenge

- **Method/Path**: `POST /api/v1/auth/biometric/verify`
- **Auth**: Bearer access token required
- **Request body**:

```json
{
  "challengeId": "uuid",
  "keyId": "key-123",
  "signatureBase64": "<signature>"
}
```

- **Response**:

```json
{
  "stepUpToken": "<jwt>",
  "expiresAt": "2026-02-19T16:35:00Z"
}
```

## 2) Step-Up Enforcement Header

The following endpoints require step-up token header:

- `POST /api/v1/biometric/enroll/{userId}`
- `POST /api/v1/biometric/verify/{userId}`

Required header:

```http
X-Step-Up-Token: <stepUpToken>
```

If missing/invalid, API returns `403` with error code `STEP_UP_REQUIRED`.

## 3) Encoding Rules (Frozen)

### 3.1 `nonceBase64`

- Contract format: **standard Base64 (RFC 4648)** string.
- Generated by backend with standard Base64 encoder.

### 3.2 `signatureBase64`

- Contract format: **standard Base64 (RFC 4648)** string.
- Backend currently accepts Base64URL as fallback for compatibility, but clients should send standard Base64.

### 3.3 `publicKeyJwk`

- Contract format: **JSON object** (not a JSON string).
- Required fields:
  - `kty` = `EC`
  - `crv` = `P-256`
  - `x` (Base64URL coordinate)
  - `y` (Base64URL coordinate)
- Optional field:
  - `kid`

## 4) Security Semantics

- Challenge is one-time use.
- Challenge has short TTL (backend default: `90s`).
- Step-up token has short TTL (backend default: `5m`).
- Step-up JWT contains `amr` including `"biometric"`.

## 5) Error Shape

Standard error response:

```json
{
  "timestamp": "2026-02-19T16:00:00Z",
  "status": 403,
  "error": "STEP_UP_REQUIRED",
  "message": "Biometric step-up is required for this operation.",
  "path": "/api/v1/biometric/enroll/..."
}
```
